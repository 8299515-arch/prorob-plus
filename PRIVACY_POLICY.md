# Политика конфиденциальности «Прораб+»

Дата вступления в силу: 22 августа 2026 года

Приложение «Прораб+» предназначено для управления строительными объектами, задачами, финансами, контактами и документами.

## Какие данные обрабатываются

В зависимости от используемых функций сервис может обрабатывать данные учетной записи, сведения о проектах и задачах, финансовые записи, контактные данные клиентов/подрядчиков/сотрудников и загруженные пользователем документы.

## Для чего используются данные

Данные используются исключительно для предоставления функций приложения, синхронизации с сервером, авторизации и обеспечения безопасности сервиса.

## Хранение и защита

Доступ к учетной записи осуществляется с использованием токена авторизации. Токен на Android хранится в защищенном хранилище устройства. Передача данных между приложением и API должна выполняться по HTTPS.

## Передача третьим лицам

Мы не продаем персональные данные пользователей. Данные могут обрабатываться поставщиками инфраструктуры, необходимыми для работы сервиса, в пределах предоставления соответствующей функции.

## Удаление данных

Пользователь может запросить удаление учетной записи и связанных с ней данных через службу поддержки сервиса. Запрос должен содержать идентификатор учетной записи и быть направлен с адреса, связанного с учетной записью.

## Контакты

Контактный адрес службы поддержки должен быть опубликован владельцем сервиса перед размещением приложения в Google Play.

## Изменения политики

При существенных изменениях политики новая версия будет опубликована в репозитории и по публичному адресу политики конфиденциальности.
